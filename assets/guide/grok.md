## Grok Build worker
- Uses the native `grok` CLI and its existing login, configuration and project rules. `{{CLI}} doctor` checks the required headless capabilities without starting inference. Update Grok if `streaming-messages-json` or `--prompt-file` is unavailable.
- `{{CLI}} models --worker grok` reads the native account catalog. Without `--model`, Grok chooses its configured model; the run pins the model reported by `system/init` for exact-session resumes. `--effort` accepts the selected model's reasoning levels (native Grok validates support). Provider routing stays in Grok; do not switch providers to work around a blocker.
- **X search is a first-class research source.** Use it for original announcements, maintainer discussions, practical examples and recent developments on X. In the brief, request native X search explicitly when relevant, with search terms/accounts/date ranges and direct post URLs, authors and dates in the discovery packet. Distinguish firsthand evidence from opinions or reposts; confirm decisive technical claims against primary documentation or code.
- The dispatcher does not restrict Grok's tool list or disable web search. X search availability still depends on the selected model, account and native settings. If unavailable, report that gap rather than presenting ordinary web results as X-search evidence. Search inputs and results remain visible in the dashboard's on-demand event content and session export, not compact status/callbacks.
- Prompts travel through a UTF-8 file inside the run directory, not command-line arguments. Telemetry and the raw stream stay in that run; native credentials and preferences are never edited. `resume` uses only the saved session UUID, never the latest session. `--mode plan` requests Grok's native plan permission mode; discovery also retains the normal worktree guard.
- Quota/authentication failures are blockers. Missing terminal output is unconfirmed completion, even after exit zero. A research-only request can finish at its discovery packet; do not invent an implementation stage.

Native format reference: [Grok headless mode](https://github.com/xai-org/grok-build/blob/main/crates/codegen/xai-grok-pager/docs/user-guide/14-headless-mode.md).
